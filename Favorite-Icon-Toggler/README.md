# ❤️ Favorite Icon Toggler

An interactive web application built with HTML, CSS, and JavaScript that allows users to add or remove items from their favorites by clicking a heart icon.

## Features

- Three favorite items.
- Toggle between empty and filled heart icons.
- Dynamic button styling.
- Interactive click events.
- Responsive and clean user interface.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
Favorite-Icon-Toggler/
├── index.html
├── styles.css
├── script.js
└── README.md
```

## How to Run

1. Open the project folder.
2. Open `index.html` in a web browser.
3. Click a heart icon to add an item to favorites.
4. Click again to remove it from favorites.
