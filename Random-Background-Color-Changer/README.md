
# ColorFlow – Random Background Color Changer

A modern and responsive random background color generator built using HTML, CSS, and JavaScript.

## Features

- Generate random dark background colors.
- Display the current HEX color code.
- Copy HEX codes to the clipboard.
- Smooth background color transitions.
- Responsive design for desktop and mobile.
- Accessible interface with keyboard focus support.

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)

## Project Structure

```text
Random-Background-Color-Changer/
├── index.html
├── styles.css
├── script.js
└── README.md
```

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Click **Generate new color** to change the background.
5. Click **Copy code** to copy the current HEX value.
