
# fCC Forum Leaderboard

A responsive forum leaderboard that displays the latest discussions
from the freeCodeCamp community.

## Overview

The fCC Forum Leaderboard retrieves live discussion data from the
freeCodeCamp Forum API and displays topics, categories, user avatars,
replies, views, and recent activity.

The project focuses on practicing JavaScript fundamentals and
working with asynchronous API requests.

## Features

- Fetches the latest forum topics using the Fetch API.
- Displays topic titles and category links.
- Shows user profile avatars.
- Calculates the number of replies.
- Formats large view counts.
- Displays relative activity timestamps.
- Responsive layout for desktop and mobile devices.
- Modern dark-themed dashboard interface.

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API
- Async/Await
- DOM Manipulation

## API

The application retrieves forum data from:

https://cdn.freecodecamp.org/curriculum/forum-latest/latest.json

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Make sure you have an internet connection to retrieve live forum data.

You can also use the Live Server extension in Visual Studio Code.
