
# ⚽ Football Team Cards

A responsive football team roster application built with HTML, CSS, and JavaScript.

Users can explore the team's players and filter the roster by playing position.

## Features

- Football team information and head coach details
- Dynamic player cards
- Captain identification
- Filter players by position
- All Players option to display the complete squad
- Responsive layout for desktop, tablet, and mobile
- Clean, modern dark interface

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)
- DOM Manipulation
- Array filter() method

## Project Structure

Football-Team-Cards/
├── index.html
├── styles.css
├── script.js
└── README.md

## How to Run

1. Clone or download this repository.
2. Open the Football-Team-Cards folder.
3. Open index.html in your browser.
4. Select a position from the dropdown to filter players.

## Available Filters

- All Players
- Position Forward
- Position Midfielder
- Position Defender
- Position Goalkeeper
