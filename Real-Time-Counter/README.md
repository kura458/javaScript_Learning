# Real Time Character Counter

A simple JavaScript project that counts characters as the user types.

## Features
- Real-time character counting
- Maximum limit of 50 characters
- Automatically trims extra characters
- Counter turns red when the limit is reached

## Technologies
- HTML5
- CSS3
- JavaScript

## How to Run
1. Open `index.html` in your browser.
2. Type into the textarea.
3. Watch the character counter update.
