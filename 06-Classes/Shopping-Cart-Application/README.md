
# Sweet Treats - Shopping Cart Application

A beginner-friendly shopping cart application built with HTML, CSS, and JavaScript as part of the freeCodeCamp JavaScript curriculum.

## Features

- Display 12 dessert products.
- Add products to the shopping cart.
- Track individual product quantities.
- Calculate the subtotal.
- Calculate 8.25% sales tax.
- Calculate the final cart total.
- Show and hide the shopping cart.
- Clear the cart with confirmation.
- Responsive layout for desktop and mobile.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- JavaScript Classes
- Array Methods
- DOM Manipulation
- Event Listeners
- Template Literals

## How to Run

1. Clone or download this repository.
2. Open the Shopping-Cart-Application folder.
3. Open `index.html` in your browser.
4. Add desserts to your cart.
5. View the subtotal, taxes, and final total.
6. Use Clear Cart to empty your shopping cart.

## Tax Rate

The application uses an 8.25% tax rate.
