
# Bank Account Management System

A beginner-friendly Bank Account Management System built with JavaScript ES6 classes.

This project demonstrates object-oriented programming concepts through a simple banking application.

## Features

- Create a bank account with an initial balance of $0.
- Deposit money into an account.
- Withdraw money with balance validation.
- Check the current account balance.
- Track all deposit transactions.
- Track all withdrawal transactions.
- Maintain a transaction history.

## Technologies Used

- JavaScript (ES6+)
- Node.js
- Object-Oriented Programming

## How to Run

Make sure Node.js is installed.

Open CMD inside the project folder and execute:

```bash
node index.js
```
