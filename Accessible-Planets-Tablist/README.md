# 🌍 Accessible Planets Tablist

An interactive and responsive planet explorer built with **HTML, CSS, and JavaScript**. Explore Earth, Saturn, and Mars through an accessible tab-based interface.

## 🚀 Live Features

- Interactive planet selection.
- Accessible tab navigation using ARIA attributes.
- Keyboard navigation with Left, Right, Home, and End keys.
- Responsive design for desktop, tablet, and mobile.
- Modern dark space-inspired interface.
- Planet facts and information.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- ARIA Accessibility

## 🎮 Keyboard Controls

| Key | Action |
|---|---|
| Right Arrow | Next planet |
| Left Arrow | Previous planet |
| Home | First planet |
| End | Last planet |
