# 📖 Storytelling App

A simple and interactive storytelling web application built with **HTML, CSS, and JavaScript**.

Choose your favorite story genre and enjoy a short story! Each story has its own unique border color.

## 🚀 Features

- **Scary Story:** Discover a mysterious and frightening story.
- **Funny Story:** Enjoy a humorous camping adventure.
- **Adventure Story:** Explore an exciting journey through the Amazon rainforest.
- Interactive buttons for selecting stories.
- Dynamic story display using JavaScript.
- Different border colors for each story genre.
- Simple and responsive user interface.

## 🛠️ Technologies Used

- HTML5 – Application structure.
- CSS3 – Styling and layout.
- JavaScript – Interactive functionality and DOM manipulation.

## ▶️ How to Run

1. Clone or download this repository.
2. Open the `Storytelling-App` folder.
3. Double-click `index.html` to open the application in your browser.
4. Click one of the three story buttons:
   - Scary Story
   - Funny Story
   - Adventure Story
5. Enjoy your story!
