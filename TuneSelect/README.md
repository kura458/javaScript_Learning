
# TuneSelect – Music Instrument Store

TuneSelect is a responsive music instrument filtering application built with HTML, CSS, and JavaScript.

It allows users to explore a collection of student musical instruments and filter products by category.

## Features

- Browse all available instruments.
- Filter by Woodwinds, Brass, and Percussion.
- Dynamic product card generation.
- Automatic product count updates.
- Responsive layout for desktop, tablet, and mobile.
- Modern dark interface with gold accents.
- Interactive hover effects.

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)
- DOM Manipulation
- Array filter()
- Array map()
- Array join()
- Template Literals

## How to Run

1. Clone or download the repository.
2. Open the TuneSelect folder.
3. Open index.html in your browser.
4. Select a category to filter the instruments.

- Filtering data with filter().
- Generating HTML using map().
- Combining HTML strings using join().
- Handling dropdown change events.
- Updating webpage content using innerHTML.
