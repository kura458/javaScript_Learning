
# BookFinder – Library Book Search

A responsive library search application built with HTML, CSS, and JavaScript.

## Features

- Search for books in a predefined library collection.
- Case-insensitive book title matching.
- Input validation and error handling.
- Success and error feedback.
- Automatic input clearing after every search.
- Keyboard support using the Enter key.
- Responsive design for desktop and mobile devices.

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)

## Project Structure

```text
Library-Book-Search/
├── index.html
├── styles.css
├── script.js
└── README.md
```

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Enter a book title and click Search.
