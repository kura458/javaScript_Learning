
# Decimal & Binary Converter

A responsive, bidirectional number converter built using HTML, CSS, and JavaScript.

## Features

- Decimal to Binary conversion
- Binary to Decimal conversion
- Recursive decimal-to-binary algorithm
- Interactive recursion call-stack animation
- Input validation
- Copy conversion results
- Clear and reset functionality
- Responsive interface

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## Example Conversions

| Decimal | Binary |
|---:|---:|
| 5 | 101 |
| 6 | 110 |
| 10 | 1010 |
| 25 | 11001 |

## Learning Objectives

This project demonstrates recursion, function calls, number systems,
input validation, DOM manipulation, and event handling.
