
# WeatherNow – Weather App

A responsive weather dashboard that displays current weather information for six major cities around the world.

## Features

- Search weather by selecting a city.
- Display current temperature in Celsius.
- Display feels-like temperature.
- Show weather conditions and weather icons.
- Display humidity.
- Display wind speed and wind gust.
- Handle missing API values with N/A.
- Handle API errors with user-friendly alerts.
- Responsive interface for desktop and mobile devices.

## Available Cities

- New York
- Los Angeles
- Chicago
- Paris
- Tokyo
- London

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API
- Async/Await
- DOM Manipulation

## Weather API

The project uses the freeCodeCamp Weather API:

https://weather-proxy.freecodecamp.rocks/api/city/

## How to Run

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html using Live Server.
4. Select a city.
5. Click Get Weather.

An internet connection is required to retrieve weather data.
