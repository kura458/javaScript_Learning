
# Theme Studio – Theme Switcher

A responsive theme switcher web application built with HTML, CSS, and JavaScript. Theme Studio lets users personalize the interface by choosing between three carefully designed color themes.

## Live Themes

- **Ocean:** A calm blue atmosphere.
- **Sunset:** A warm, creative atmosphere.
- **Forest:** A refreshing green atmosphere.

## Features

- Three interactive color themes.
- Dynamic theme switching without reloading the page.
- Live theme preview and personalized messages.
- Accessible dropdown menu with ARIA attributes.
- Keyboard support for theme selection.
- Responsive layout for desktop and mobile screens.
- Reduced-motion accessibility support.
- Smooth visual transitions.

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- Google Fonts

3. Open `index.html` in your browser.

## How to Use

1. Open Theme Studio in your browser.
2. Click **Switch Theme**.
3. Select Ocean, Sunset, or Forest.
4. The page colors, theme title, and description update immediately.
