
# WordMirror – Palindrome Checker

WordMirror is a responsive JavaScript application that checks whether words and phrases are palindromes.

A palindrome reads the same forward and backward when punctuation, spaces, symbols, and capitalization are ignored.

## Features

- Checks words, phrases, and numbers.
- Ignores punctuation and whitespace.
- Handles uppercase and lowercase letters.
- Provides instant results.
- Includes example phrases for quick testing.
- Responsive desktop and mobile design.

## How to Run

1. Clone or download the repository.
2. Open the Palindrome-Checker folder.
3. Open `index.html` in your browser.
4. Enter a word or phrase.
5. Click Check palindrome.
