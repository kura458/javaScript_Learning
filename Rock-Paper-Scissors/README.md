
# Rock, Paper, Scissors

A browser-based Rock, Paper, Scissors game where you compete against the computer. The first player to reach three points wins!

## Features

- Play against a randomly generated computer choice.
- Real-time score updates.
- Automatic winner detection.
- Play Again functionality.
- Responsive design for desktop and mobile.
- Accessible buttons and game announcements.

## Technologies

- HTML5
- CSS3
- JavaScript (DOM Manipulation and Event Handling)

## How to Run

1. Clone this repository.
2. Open the `Rock-Paper-Scissors` folder.
3. Open `index.html` in your browser.
4. Choose Rock, Paper, or Scissors and play!

## Game Rules

- Rock beats Scissors.
- Scissors beats Paper.
- Paper beats Rock.
- Matching choices result in a tie.
- First to three points wins.
