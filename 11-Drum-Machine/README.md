
# 🥁 BeatLab - Drum Machine

A responsive and interactive drum machine built with HTML, CSS, and JavaScript.

Play nine different drum sounds using your keyboard or by clicking the drum pads.

## ✨ Features

- Nine interactive drum pads.
- Keyboard controls: Q, W, E, A, S, D, Z, X, C.
- Click-to-play functionality.
- Real-time sound display.
- Animated pad feedback.
- Responsive design.
- Audio playback using the HTML Audio API.

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript (ES6)
- DOM Manipulation
- HTML Audio API
- Event Listeners

## 🎹 Keyboard Controls

| Key | Sound |
|---|---|
| Q | Heater 1 |
| W | Heater 2 |
| E | Heater 3 |
| A | Heater 4 |
| S | Clap |
| D | Open HH |
| Z | Kick n Hat |
| X | Kick |
| C | Closed HH |

## 🚀 How to Run

1. Download or clone the repository.
2. Open the `11-Drum-Machine` folder.
3. Open `index.html` in your browser.
4. Click a drum pad or press its keyboard key.
