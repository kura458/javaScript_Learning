
# TaskFlow - Task Management Application

A responsive task management application built using HTML, CSS, and Vanilla JavaScript.

## Features

- Create new tasks
- Edit existing tasks
- Delete tasks with confirmation
- Mark tasks as completed or active
- Search tasks by title or description
- Filter tasks by status
- Display task statistics
- Save tasks using browser Local Storage
- Responsive design for desktop and mobile
- Safe DOM rendering of user-provided task content

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- Browser Local Storage

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start creating and managing tasks.

No backend or installation is required.
