
# MeasureMate – Recipe Ingredient Converter

MeasureMate is a responsive recipe ingredient conversion application that helps users convert common kitchen measurements and adjust ingredient quantities for different serving sizes.

## Features

- Convert between cups, grams, ounces, and teaspoons.
- Adjust ingredient quantities based on servings.
- Display conversion results instantly.
- Responsive design for desktop and mobile.
- Input validation.
- Clean and accessible user interface.

## Technologies Used

- HTML5

- JavaScript (ES6+)
- DOM Manipulation

- Curried Functions

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Enter an ingredient, quantity, measurement unit, and number of servings.
5. Click **Convert Measurements**.

No installation or build tools are required.

## Example

Input:

- Ingredient: Flour
- Quantity: 2
- Unit: Cup
- Servings: 3

Expected conversions:

- Flour: 1440.00 gram
- Flour: 48.00 ounce
- Flour: 288.00 teaspoon
