
# Envelope Budgeter

A responsive personal finance application built with HTML, CSS, and JavaScript. It helps users organize monthly expenses, calculate total spending, and understand their remaining budget.

## Features

- Enter total monthly income.
- Add fixed expenses such as rent.
- Dynamically add expenses to different categories.
- Organize expenses into Food, Utilities, and Entertainment.
- Calculate total expenses and remaining income.
- Identify when spending exceeds the available budget.
- Clear the form and start a new budget.
- Responsive layout for desktop and mobile screens.

## Technologies

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## How to Run

1. Clone or download this repository.
2. Open the `13-Envelope-Budgeter` folder.
3. Open `index.html` in your browser.
4. Enter your monthly income.
5. Add your expenses.
6. Click Calculate Budget to view the results.

## Budget Calculation

Total Expenses = Rent + Food + Utilities + Entertainment

Remaining Budget = Total Income - Total Expenses
