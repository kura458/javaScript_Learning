
# 😊 Emoji Reactor

An interactive web application that allows users to rate their emotions using emoji buttons.

Each emotion has an individual counter that increases when the user clicks its button. The counter stops increasing when it reaches 10.

## 🚀 Features

- Four interactive emotion buttons.
- Happy 😊 emotion counter.
- Confused 😕 emotion counter.
- Sad 😢 emotion counter.
- Loving 😍 emotion counter.
- Individual counters for each emotion.
- Maximum rating of 10 for each button.
- Responsive design for mobile and desktop.
- Accessible button labels.
- Interactive hover effects.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## ▶️ How to Run

1. Clone or download the repository.
2. Open the `Emoji-Reactor` folder.
3. Open `index.html` in your web browser.
4. Click any emoji button to increase its counter.
5. Each counter stops at 10.
