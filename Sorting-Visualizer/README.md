
# SortLab – Bubble Sort Visualizer

An interactive Bubble Sort visualizer built with HTML, CSS, and JavaScript.

SortLab demonstrates how the Bubble Sort algorithm works by displaying each comparison and the resulting array state.

## Live Demo

Open `index.html` in your browser to run the application locally.

## Features

- Generate five random integers between 1 and 100.
- Visualize Bubble Sort step by step.
- Highlight the two elements being compared.
- Display array states after each comparison.
- Show the final sorted array.
- Generate a new array and restart the visualization.
- Responsive interface for desktop and mobile devices.

## How to Run

1. Clone or download the repository.
2. Open the `Sorting-Visualizer` folder.
3. Open `index.html` in your browser.
4. Click **Generate** to create a random array.
5. Click **Sort array** to visualize Bubble Sort.

## How Bubble Sort Works

Bubble Sort repeatedly compares adjacent elements.

1. Compare two neighboring numbers.
2. Swap them if the left number is greater.
3. Continue through the array.
4. Repeat until a complete pass requires no swaps.

## Algorithm Complexity

| Measurement | Complexity |
|---|---|
| Best case | O(n) with early stopping |
| Average case | O(n²) |
| Worst case | O(n²) |
| Auxiliary space | O(1) |
