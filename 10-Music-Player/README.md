
# 🎵 Melody - Music Player

A responsive music player application built with HTML, CSS, and JavaScript.

Melody allows users to play, pause, and navigate through a playlist with a clean and modern interface.

## ✨ Features

- Play and pause music.
- Skip to the next song.
- Return to the previous song.
- Automatically play the next song when the current song ends.
- Select songs directly from the playlist.
- Highlight the currently playing song.
- Display current song title and artist.
- Responsive design for desktop and mobile.
- Accessible player controls.

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript (ES6)
- HTML Audio API
- DOM Manipulation
- JavaScript Array Methods
- Event Listeners

## 🚀 How to Run

1. Clone or download the repository.
2. Open the `10-Music-Player` folder.
3. Open `index.html` in your browser.
4. Select a song and enjoy!

You can also use the VS Code Live Server extension.
